Entrants send exactly one emoji for their dream vacation and a judge picks the most evocative. Free to enter, one winner takes the whole reward.

Entry: 🗼 — one emoji, the Tokyo Tower, the single postcard image of a dream trip to Tokyo. Chosen after full-field research over all 842 entries: the field is dominated by desert islands (128 titles), Mount Fuji (118), sunrises (69) and beaches (53), while a city landmark appears in only 1 title — so the tower is the freshest angle, plainly names one specific dream trip, and reads instantly at any size.

## Run it

```sh
python3 main.py
```

Writes exactly one emoji (🗼, U+1F5FC, 4 bytes UTF-8, no trailing newline) to `/output/entry.txt`.
